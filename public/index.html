TIXKEN

Tokenized tickets for live events, running on the Elysium testnet.

Not connected

Contract

Connect your wallet to begin. The page will switch it to Elysium Testnet (chain ID 99801).

Create an event

Only the organizer wallet (the one that deployed the contract) can create events and issue tickets.

Set the reclaim agent

The agent wallet can only reclaim tickets that were never scanned, after the event has ended.

Issue a ticket

Organizer wallet only. The ticket goes straight to the attendee's wallet.

Look up a ticket

My tickets

Scans recent activity on the contract for tickets held by the connected wallet.

Door scan

The ticket holder or the organizer confirms entry. The ticket is burned on-chain and the holder's attendance is recorded.

List a ticket for resale

The contract rejects any price above the event's resale cap.

Buy a listed ticket

You pay the asking price in HYPE and the seller is paid directly.

Reclaim an unused ticket

Agent wallet only, and only after the event has ended. The ticket is burned, and in credit mode the holder receives a credit.

Credits

Use a credit

Spend one credit to receive a ticket to an upcoming event.

Leaderboard

Attendees ranked by events attended, built from recent door scans.
